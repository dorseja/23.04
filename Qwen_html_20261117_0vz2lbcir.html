О проекте

«Немецкий словарик» — учебный проект по курсу «Основы программирования». Вся логика написана на Python (файл slovarik.py) и выполняется прямо в браузере через Pyodide — интерпретатор Python на WebAssembly. JavaScript отвечает только за отрисовку интерфейса.

Функции программы

  • Просмотр словаря, фильтр по 13 темам, поиск по части слова
  • Мини-тест: немецкий → русский и русский → немецкий
  • Тренажёр артиклей der / die / das
  • Добавление, редактирование, удаление слов
  • Статистика: уникальные слова, повторы, средняя длина слова
  • Экспорт в CSV и TXT, импорт из TXT, автосохранение
