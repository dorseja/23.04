# 🇩🇪 Немецкий словарик — Python в браузере

Учебный проект по курсу «Основы программирования».
Вся логика написана на **Python** и выполняется прямо в браузере через **Pyodide**
(интерпретатор Python на WebAssembly). JavaScript отвечает только за интерфейс.
Сайт опубликован на GitHub Pages.

## Возможности
- Просмотр словаря: 373 слова, 13 тем, фильтр и поиск по части слова
- Мини-тест: немецкий → русский и русский → немецкий, оценка за результат
- Тренажёр артиклей der / die / das
- Добавление, редактирование и удаление слов
- Статистика: уникальные слова, повторы, средняя длина слова, слова по темам
- Экспорт в CSV (Excel) и TXT, импорт из TXT, автосохранение в браузере

## Файлы
| Файл | Назначение |
|---|---|
| slovarik.py | вся логика на Python + консольное меню |
| index.html | интерфейс страницы |
| style.css | оформление |
| app.js | вызов функций Python и отрисовка |

## Запуск
- Сайт: https://ТВОЙ_ЛОГИН.github.io/nemetskiy-slovarik/
- Консоль: `python slovarik.py` (или одна ячейка в Jupyter)
- Локально в браузере: `python -m http.server 8000` → http://localhost:8000

Первое открытие сайта занимает 10–30 секунд: браузер скачивает интерпретатор Python,
затем он сохраняется в кэше.
